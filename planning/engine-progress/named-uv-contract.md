# Named UV implementation contract

Final interface decisions are in [docs/named_uv.md](../../docs/named_uv.md).
Acceptance must include analytic UV-role/normal/footprint/bake/alpha/displacement
tests, native CLI and browser/OPFS workflows, negative/stale/cancellation/budget
checks, explicit Metal execution, portability compilation, resource/provenance
evidence and unchanged prior default-profile pixels. Capability status remains
unchanged until acceptance completes.
