# Morph-frame implementation contract

Final interface decisions are in [docs/morph_frames.md](../../docs/morph_frames.md).
Acceptance requires analytic normal/tangent and nonuniform/reflected skinning,
dense/sparse equivalence, point/corner identity, default-policy preservation,
zero/singular/missing-base/bad-count failures, cancellation and stale revisions,
native CLI and browser OPFS recovery, CPU/Metal/WebGPU frame/shutter comparisons,
resource/provenance evidence and unchanged prior profile artifacts. Capability
status remains unchanged until the complete native and browser workflows pass.
