# Structural container fixtures

Original CC0 data generated by `generate.py`. Four files cover 32/64-bit relocation
identifiers and little/big byte order. Each declares a minimal Node structure,
a two-element typed block, a separately addressed node, and advisory REND metadata
whose temporary token aliases an addressable block. These are structural test
containers, not Blender application scenes.

The Rust reader tests check exact numeric decoding and relocation, all truncated
prefixes, malformed header/DNA/count/layout/token cases, nonfinite accessed values,
input bounds, cancellation and C declaration shape checks. Structural versions
250–399 are distinguishable from the semantic version 293 scene importer.

Reproduce into a temporary output directory and compare against `data`; never
replace expected files automatically when a test fails. The final static-import
evidence collector performs this comparison for both fixture families.
