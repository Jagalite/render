# Animated input fixtures

`character.gltf`, `character.bin` and `character.glb` are original synthetic data
created for this repository. The four-point ribbon has hip/shoulder joints,
normalized byte weights, a position morph, cubic root translation, linear joint
rotation and stepped morph weights. The mesh node is translated five meters to
exercise glTF's cancellation of the skinned mesh-node transform. A closed-form
reference in `crates/core/tests/animated_gltf.rs` checks actual deformed positions.

`generate.py <new-directory>` reproduces the three files without overwriting the
reviewed fixture. It writes glTF binary fields directly; no engine or Blender is
used to generate the input.

`khronos-simple-skin/` contains unchanged source files from Khronos glTF Sample
Assets, authored by Marco Hutter under CC0. Its source README includes attribution.
The imported fixture contains rounded quaternion keys; the explicit PBR
approximation policy admits and reports the small normalization correction.
The downloaded README's upstream relative image/catalog links are archival.

Hashes, URLs and licenses are recorded in `provenance.json`. No fixture is a
reference image, and no existing image golden is regenerated by this work.
