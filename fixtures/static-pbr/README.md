lengths and SHA-256 hashes in each `provenance.json`:

- [BoxTextured](BoxTextured/UPSTREAM_README.md): ©2017 Cesium, CC BY 4.0.
  Its ©2015 Cesium logo also carries the [upstream trademark notice](BoxTextured/LicenseRef-LegalMark-Cesium.txt).
- [NormalTangentMirrorTest](NormalTangentMirrorTest/UPSTREAM_README.md):
  ©2018 Analytical Graphics, Inc., Ed Mackey, CC BY 4.0.

Both original JSON/resource and binary GLB forms are retained. Upstream README
links retain their original repository-relative paths. Reproduction, budgets,
procedural analytic fixtures and measured results are described in
[the static PBR profile](../../docs/static_pbr.md) and
[its evidence](../../evidence/static-pbr/README.md).
