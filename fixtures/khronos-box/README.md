# Khronos Box fixture

Box by **Cesium**, copyright 2017 Cesium, licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode).
Credit: Cesium for Everything. Original asset bytes are unmodified.
[Upstream attribution](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Box).
Exact URLs, byte sizes and SHA-256 identities are in `provenance.json`.

M05 uses its indexed triangles, normal attribute, two-node matrix hierarchy and
explicit red material. Conversion to two-sided Lambertian omits dielectric
specular. Test variants change colors/lighting; synthetic hierarchy tests derive
modified JSON in memory. Those changes do not overwrite these source files.
