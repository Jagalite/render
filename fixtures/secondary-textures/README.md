# Original secondary texture fixture

CC0 geometry, checker texture and source recipe are generated with Python's standard
library by `generate.py <new-directory>`. Four embedded GLBs and matching JSON/BIN
sources vary only floor opacity mode and emitter minification filter. The fixed
magnification filter is nearest; wraps clamp. Data/provenance reproduce byte for byte.

The floor is a unit quad at z0; the checker ceiling is scaled fourfold at z2.
An orthographic camera at z1 looks down: the untextured floor is primary, and the
32x32 black/white emissive checker appears only after a bounce. Tests use 8x8 pixels,
32 samples, depth2 and no point/environment illumination. The CLI recipe applies
five typed native surface models through ordinary material transactions.

Primary controls look directly at the ceiling, or move it behind a fully discarded
MASK floor. The latter uses 4x4 pixels, giving 1.8 texels per pixel; the initial
8x8 test had a 0.9-texel footprint and correctly did not exercise minification.
No rendered golden images are generated by this source script.
